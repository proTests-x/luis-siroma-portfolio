# Portafolio de Luis Angel Siroma Lozano

Portafolio personal desarrollado con Angular y Three.js.

## Tecnologías

- Angular
- TypeScript
- Three.js
- SCSS

## Desarrollo local

```bash
npm install
npm start
```

## Compilación

```bash
npm run build
```

El sitio se publica automáticamente en GitHub Pages desde la rama `main`.
